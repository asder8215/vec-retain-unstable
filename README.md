The whole purpose of this repository is to store different implementations of `Vec::retain_unstable` as well as benchmark data. There's also a baseline benchmark data on `Vec::retain` to compare the situations where `Vec::retain_unstable` performs worse or better than `Vec::retain_unstable` (ideally we want better performance, but that may not be the case always). You can find all data/implementations in the `retain_unstable_benchmarks` directory.
